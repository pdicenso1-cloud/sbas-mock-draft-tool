# FantasySync v6.4.8 — Manual Draggable Player Tray

- Replaces the unreliable arrow controls with one centered drag grip.
- Grip sits at the top edge of the player tray in the requested location.
- Drag upward to reveal more player/queue/roster content.
- Drag downward to expose more of the draft board.
- Tray height persists through CPU reruns using browser local storage.
- Safe range: 52 px collapsed to 560 px maximum.
- Player list and utility panel heights scale with the tray.
- All board width, colors, R1-R16 scrolling, roster, autorefresh, CPU speed,
  timer, keeper, trade, and draft logic are preserved.
